## Правило (записано ДО чтения ранжирования; изменение — только отдельной строкой «поправка» с причиной)

**Данные.** Клетки БД: вселенная `c539` (крипта, В-175), окно 01.07–13.11, ставка 500 $ (маржа 250 $); записи L-333 / L-334 / L-336 / L-337 и далее (шаг 3 — L-344 и поздние, по мере записи); бинари 9387e0a9 / c06f6674 / c64d5ed7 (гейт «байт в байт» по базе); повтор ключа в двух бинарях сверяется (сделки, Σ $) и считается один раз, расхождения выводятся. Июньское окно (wj) и сутки ≥ 14.11 не читаются.

**Якорь** стороны — клетка L-334 (лонг: стоп 3 %; шорт: стоп 4 %).

**Ось.** Ось = семейство ключей движка (таблица семейств в коде: split = e2 / e2t / w2 / s2; ev-зона = ev / ea / el / eh; nf с natr_min; канал = ch / cl / cm / cw; форма NATR-стопа = sn / sg / sb / sd / sr; rf с rs; tt с tb; e1t и xb с e2 при обнулении; sm — спутник оси стопа от уровня / NATR / канала) или один ключ или один столбец фильтра. Клетка = набор активных осей (отличие от якоря); **уровень клетки k = число осей**. Номер оси — «№» вкладки «Признаки» (`tools/p42/ml_features.json`), где есть.

**Эффект оси a на уровне k.** Для каждой клетки C уровня k с осью a берётся опорная клетка C∖a (те же оси без a; уровень k − 1; для k = 1 — якорь). Δ = метрика(C) − метрика(C∖a), метрики: Σ $, $ на сделку, сделок, Шарп, просадка $ (и % маржи), перехай (самый длинный, сут.), R:R. Эффект оси на уровне = число клеток с опорой n_k, среднее Δ, разброс min…max, доля клеток с Δ Σ $ > 0. Клетки без опорной клетки в БД в оценку не входят (их число выводится). Уровни не усредняются между собой; вывод на уровне k относится только к уровню k.

**Размер.** Прибыль: rP = среднее |Δ Σ $| / |Σ $ якоря|; убыток: rD = среднее |Δ просадки $| / просадка $ якоря (лонг: 326 $ и 41 $; шорт: 134 $ и 26 $ — L-334). r = max(rP, rD).

**Группы** (по стороне, уровню и оси отдельно; пороги заданы до просмотра):
1. «много» — r ≥ 0,30;
2. «мало» — 0,05 ≤ r < 0,30;
3. «ничего» — r < 0,05 или мёртвый ключ (во всех клетках оси на уровне trades_sig клетки = trades_sig опоры);
оси с n_k < 2 не группируются («не оценена»). Группы по прибыли (rP) и убытку (rD) показываются отдельно теми же порогами. Устойчивость в группу не входит, показывается флагом: знак Δ Σ $ у клеток оси совпадает со знаком среднего у ≥ 75 % клеток; из 5 месяцев (`months` клетки) знак среднего Δ месяца совпадает со знаком среднего Δ за окно в ≥ 4.

**Шум отбора** — как в L-338 / L-349: σ(Шарп клеток уровня) × √(2 ln m), m = различные ключи стороны под c539 + под h775; сравнивается с max |Δ Шарпа| оси (не с уровнем Шарпа, L-351); для $ — та же формула с σ(Σ $ клеток уровня). Сверка метода: на уровне 2 σ и шум должны воспроизвести L-349 (лонг σ 2,03 → 9,39; шорт 1,57 → 7,36; допуск — число клеток выросло).

**Кластеры** («одно и то же»): среди осей, не попавших в «ничего». Уровень 1 — пересечение сделок: для клетки оси затронутые сделки = есть только у якоря или только у клетки (ключ — монета + время входа), пересечение двух осей = среднее по парам значений осей |A ∩ B| / min(|A|, |B|); ребро при ≥ 0,5; семья = компонента связности из ≥ 2 осей; представитель — ось с наибольшим r. Уровни ≥ 2 — приближение по дневным Δ (средний по клеткам оси ряд Δ Σ $ по суткам, корреляция ≥ 0,7; не по сделкам; на уровне 1 проверяется согласие обоих способов и печатается).

**Взаимодействия** (уровни ≥ 2). Для клетки из k осей — чистая интерактивность порядка k: Σ_{T ⊆ S} (−1)^{k−|T|} Σ $(T) по всем подмножествам (T = ∅ — якорь), нужны все подклетки в БД; для k = 2 это синергия TK-674. Интервал — блочный бутстреп по суткам (блок 5, B = 20 000, seed 674, как `tk674_run.synergy`). Выводится top по знакам с интервалом, счётчик клеток с интервалом выше 0 / ниже 0 против ожидаемого случайного (2,5 % каждый знак).

**Группа NATR (первый раздел отчёта; состав задан до просмотра по описанию вкладки «Признаки»):** ключи и столбцы, в описании которых NATR — сама величина или единица оси: natr_min (1), natr_p (2), nf (252), fg (20), xb (31), ev / ea / el / eh (253–256), ls (37), sl (38), sn с формой sg / sb / sd / sr (39), nx (44), cl / ch / cm (46–48), vf / vs / va / vb / vp / v0 / vm / vz / vr (49–57), t_low (59), t_high (60), a (68), rr (69), natr_exit_p (77), ns (78), столбцы признаков natr_bp (105) и VOL (216). Не входят: mv5 / mv15 / mv60 / maxmv1 / maxrng15 / ok05_d14 (ход цены, измеренный в NATR — это не NATR-ось).

**Не покрыто (печатается в отчёте):** уровни, которых ещё нет в БД на момент запуска (тройки / четвёрки c539 — по мере записей TK-674); оси без единичных клеток; три окна wa / wb / wc по отдельности (в БД клетки лежат целым окном; по месяцам — см. выше); знак вне окна 01.07–13.11; h775 (с TradFi) как данные не используется — только как счётчик m.

## Поправки к правилу (критик `thr_m27kv64m9h`, 23.11, до чтения ранжирования; PASS без повторной проверки)

1. **Нулевая модель размера.** Для пары (клетка C, опора R), где одно множество сделок — собственное подмножество другого и на общих сделках P&L совпадает («отбор сделок»), берётся большее множество и m = |n_C − n_R|; B = 1 000 розыгрышей без возвращения (seed 689, фиксированный порядок клеток): Δ Σ $ и Δ просадки у большего множества с m случайно убранными сделками. r_null оси на уровне = среднее по розыгрышам от (среднее по клеткам оси |Δ|, в долях якоря как в r); p95 — 95-й перцентиль по розыгрышам. Метка «не отличим от случайного выкидывания», если r ≤ p95 r_null (группы по порогам 0,30 / 0,05 не меняются; метка рядом). Ось, у которой клеток-«отбор» < 50 % (меняет вход или P&L тех же сделок), — «нулевая модель не применима».
2. **Полная сетка или отбор.** Печатается по уровню и стороне: клетки из полной сетки (единичные клетки наборов; карта пар TK-674 L-337 — все совместимые пары) и клетки, взятые по результату (пары с осями TK-680 L-344, тройки, четвёрки — оси выбраны по активности / приросту / потолкам). Эффекты считаются отдельно по двум видам и не складываются; уровни с отбором помечены «оси отобраны по результату на этих данных; эффект — условный».
3. **Повторы.** Клетки с одинаковыми trades_sig у клетки и опоры считаются один раз на (ось, уровень) в n_k, среднем Δ, r и долях; сырое число — рядом.
4. **Исключены** из эффектов, кластеров и раздела NATR: клетки со стопом 5 % (В-173; в том числе двойная охрана split e2t > 0 — в таблицы владельца не идут) и клетки с ew = 0 (вход минутной свечой, В-172); их число печатается.
5. **Кластеры, уровни ≥ 2.** Узел = (ось, направление клетки: Δ сделок < 0 / > 0 / = 0 против опоры); ряд узла = среднее Δ Σ $ по суткам по клеткам узла; ребро при корреляции ≥ 0,7 между узлами разных осей; метка «приближение», не по сделкам.
