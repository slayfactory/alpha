- **Проект (до кода).**
  1. *Как уровень читают.* Фаза 1 (`candidates_fg`, `signals::scan`, `next_px`, дампы) видит `Level` только как версии цены по минутам (`segs`: с минуты → цена; жив `born ≤ t < end`); фаза 2 — только замороженную `TSig::lp` (версия минуты сигнала). Наклонная линия ложится в ту же форму без правки потребителей: по версии на каждую минуту жизни линии.
  2. *Модель.* Линия — МНК по `lk` последним подтверждённым разворотам стороны (x — середина бара точки в минутах, целая арифметика `i128`, рациональные коэффициенты, float нет; при `lk = 2` — ровно через обе точки). Версия минуты `m` — значение линии в середине минуты (`m·60 с + 30 с`), округление до 1e-8. Единственное упрощение — линия внутри минуты неподвижна, как любой уровень движка: ошибка ≤ ½ минуты наклона = при |наклоне| 2 NATR60/ч не больше 1/60 NATR60 цены (оценка по построению, **на данных не замерена** — замер: слот движка).
  3. *Пересечение на тиках.* Как у всех уровней: сделка «дошла до линии», когда цена ≥ версии минуты; сигнал — первая сделка минуты в зоне под версией, пока ни одна сделка минуты не дошла до неё (`first_signal` без правок; `dist` от версии).
  4. *Без заглядывания.* Точки — `find_pivots` (тот же код, ключи `k` / `d`, свечи `tf`); пивот известен с закрытия бара `active`, линия родится с минуты `(active+1)·tf`; в МНК только пивоты, подтверждённые к этой минуте, будущие бары не читаются (тест: мусор после рождения не меняет рождение и версии до следующего подтверждения).
  5. *Рождение и конец.* Рождение — на каждое подтверждение пивота стороны, если: набралось `lk` точек (последние по бару), цены строго падают в раме стороны (лонг — падающие максимумы, шорт — растущие минимумы: наклон против пробоя), возраст старшей точки ≤ `ld` суток, |наклон| ≤ `lsl`·NATR60[t−1]·цена в час (`lsl = 0` — без предела; мерится один раз, при рождении), ни одно закрытие бара `tf` после старшей точки не выше линии (в раме стороны, на последней минуте бара). Конец — первое из: следующее подтверждение пивота той же стороны (набор «последние `lk`» изменился — старая линия кончается, новая — другой `Level`), возраст старшей точки > `ld` суток на закрытии бара (как `l_days`), закрытие бара `tf` выше линии, цена линии ≤ 0.
