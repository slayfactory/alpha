Слова владельца (В-176): «так придумал новый признак - вход одной лимиткой за 1-2-3 тика от уровня». Исполнитель `thr_5vicaq2qz4`, ветка `bb/tk-688-entry-one-limit-key-v1-thr_5vicaq2qz4` (основа — `master` + ветка TK-683 `0f58bf0ef`). Без чтения P&L и без торговых выводов — только движок.

## Что есть в движке (по коду, до правки)

- Лот 1: тейкер по ленте (`ew`) или лимитка `mk` — `mk1`: лимит = последняя сделка стороны − тик, `mk2`: уровень без сдвига, заявка рабочая только после пробоя.
- `e2` / `e2t` — только лот 2 (часть B, у уровня), доля `w2` 5…95; лот 1 остаётся тейкером / мейкером от последней сделки.
- Ни один ключ не ставит всю ставку одной лимиткой на цене `L ∓ N·тик` → ключ `e1t`.

## Ключ `e1t` (знак — сторона)

`e1t = N` (целое, `|N| ≤ 1000`, 0 — выключен, строка `params` в `meta.json` тогда прежняя байт в байт). Требует `ew > 0` (допуск по ленте `Stale` / `Beyond`, как у `mk`); несовместим с `mk`, `ek`, `xb`, `e2`, `e2t` (и значит `w2`, `s2`), `pw`. Только `breakout tick`. Тик — `tick_at` на момент постановки заявки (нет тика — отказ `NoTick`). Вход — мейкер: комиссия мейкера, проскальзывание входа 0, счётчики заявок — `<сторона>-maker.json` (`filled / unfilled / touched`, как у `mk`). Лот один, вся ставка.

Геометрия в раме (лонг — цена как есть, шорт — цена со знаком минус; ниже «выше / ниже» — в раме, т.е. для шорта цены зеркальны):

- Заявка ставится в `сигнал + lat`, живёт до конца минуты этого момента (как у `mk`). Цена лимита `limit = grid(L) − N·тик`, где `grid(L)` — уровень, округлённый вниз на сетку последней сделки стороны (как у `mk2`). `p_sur` — последняя сделка стороны ≤ момента постановки (окно `ew`).
- Лимитная покупка стоит в книге мейкером, только пока рынок не ниже лимита (выше рынка она исполнилась бы сразу тейкером — этого в модели нет): если `p_sur ≥ limit` — заявка стоит с момента постановки; иначе — с первой сделки любой стороны `p ≥ limit` плюс `lat`. До этого момента заполнений нет.
- Заполняет первая сделка строго позже момента «заявка стоит» с ценой строго ниже лимита (сделка на цене лимита — очередь впереди — не заполняет); вход по цене лимита, время — время сквозной сделки (как `mk1`).
- `N > 0` (сторона подхода, `e1t = 1 / 2 / 3`): лимит ниже уровня на N тиков; зона `limit ≤ p < L` — как у `e2t` (`p ≥ L − N·тик`, `p < L`). Сделка `p ≥ L` до заполнения снимает заявку (`Touched`); если `p_sur ≥ L` при постановке — тоже `Touched`. Заполнение — уход цены назад ниже `L − N·тик`.
- `N < 0` (за уровнем, `e1t = −1 / −2 / −3`): лимит выше уровня на `|N|` тиков. Касание уровня заявку не снимает (пробой — ожидаемый ход); заявка встаёт после сделки `p ≥ L + |N|·тик` (+ `lat`), заполняет возврат цены строго ниже лимита — ретест после пробоя, как `mk2` со сдвигом на `|N|` тиков. Допуск `ex` (перелёт `p_sur` за уровень) — прежний, как у `mk`.
- Срок жизни: до конца минуты постановки, оба знака (допущение модели: как у `mk`; продление — отдельным решением).
