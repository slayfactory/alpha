## Найдено и исправлено при проверке (нашёл клик-тест, не «собирается»)

1. Все заявки рисовались у левого края: `logicalToCoordinate` в lightweight-charts 4.2.3 отдаёт 0 для нецелого индекса — x теперь по двум соседним целым индексам (`overlay.ts`, `x()`).
2. Круг исполнения брал долю **выставленной** заявки: у стопа и rt после тейков показывал 50 % вместо 28 % — в файл сделки добавлено поле «доля исполнения ‰» (`ord[10]`), круг и подсказка — по нему.
3. В WIP пропали стрелки входа и выхода (вместе со старой отрисовкой заявок) — вернул на отдельных рядах `mkE` / `mkX` (одна точка: вход у максимума свечи, выход у минимума), чтобы они рисовались поверх заявок.
4. Линия торгуемого уровня перекрашивала прежнюю линию «уровень» — теперь тем же цветом; подсказка с заявками на 390 закрывала панель NATR — высота ограничена графиком, не больше 3 строк на узком экране.
5. `review_loop.sh`: упавший юнит `rv-run` блокировал следующий круг — `reset-failed` перед запуском; `selection_bias.py` копируется из `/data/p42-tk743/code`.
