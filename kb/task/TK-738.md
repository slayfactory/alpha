Для протокола шага 8 ([[TK-737]], PS-1084…1088): F1 — потолок волатильности RV60 и F3 — окно часа UTC как ключи отбора кандидатов. Оценка 1,5–2,5 ч, потолок 2,5 ч, потом первым снимается F3 — **уложились, F3 в патче**.

## Сделано (28.11, ветка `bb/tk-738-engine-vx-hour-keys-v1-thr_4fb57dzt4i`)

Ключи — в `SigCfg` (`src/breakout/params.rs`), только `breakout tick`; значения по умолчанию = выкл.

| Ключ | Поле | Смысл |
|---|---|---|
| `vx=<%>` | `vx_pm` (тыс. процента, как `natr_min`) | потолок `V` = RV60 = `vol_for(8)` (тот же ряд, что `vs=8` в `volstop.rs` и `nf=8`) **закрытой минутки `t−1`**; `V > vx` — кандидата нет; нет значения `V` (−1) — кандидата нет; `0` — выкл. |
| `hr=<ч>`, `hw=<ч>` | `hr_min`, `hw_min` (минуты суток) | окно часа UTC **сигнальной минуты `t`**: проходит, если `(t mod 1440 − hr) mod 1440 < hw` — начало включено, конец исключён, заворот через полночь; `hw=0` — выкл., `hw=24` — все сутки (начало не важно); дробные часы можно (`hr=22.5`). |

- Фильтр — в `candidates_group` (`tick.rs`), рядом с `nf` / `natr_min`: `Emit.vx: Option<(&[i32], cap_e8)>` и `Emit.hour: Option<(start, width)>` готовятся один раз на задание; на событие — два сравнения целых, без аллокаций, без `f64`, время — минута суток из индекса минуты (не часы). Нет ряда RV60 у монеты — задания по ней нет (как у `nf` / `ev`).
- `level_state_key` обнуляет `vx_pm`, `hr_min`, `hw_min`: ключи только решают, выдать ли кандидата, состояние уровня не меняют — задания с разными `vx` / `hr` / `hw` делят один проход по минутам (тест: группа = отдельные проходы).
- `validate_zone`: `vx ≥ 0`; `hr ∈ [0; 24) ч`, `hw ∈ [0; 24] ч`; `hr` без `hw` — отказ (опечатка, не «выкл.»).
- **Кэш сигналов (правка критика шага 8, E2):** `cfg_key_text` (`sigcache.rs`) — поля названы в деструктуризации; `,vx_pm=…` и `,hr_min=…,hw_min=…` пишутся **только при `vx ≠ 0` / `hw ≠ 0`** → текст ключа при выключенных ключах дословно прежний (`base_key_text_matches_master` зелёный, версия кэша не менялась). `hr` без окна в ключ не входит (не действует). Задания с ключами кэшируются.
- **Минутный путь `signals.rs` (≈ строка 135):** ключи не считает — `reject_tick_only` (`cli.rs`) отказывает при `vx ≠ 0` или `hw ≠ 0`, как для `nf` / `ev`; `signals.rs` не менялся.
- `Debug` строки `params` (meta.json): поля — только при ≠ 0, строка выключенных конфигураций прежняя.

Файлы: `cli.rs`, `params.rs`, `sigcache.rs`, `tick.rs`, тесты `tick_tests.rs`, `sigcache_tests.rs`, эта карточка.
