## Дополнение 23.11 вечер (слова владельца: «в веер новое добавилось? не вижу», «лонг вообще не работает», «шорт теперь тоже не работает», «также добавь сортировку в таблицу вееров», «лист эквити делаем на всю ширину», «график на 20% выше делаем»)

**Причина «L-5: HTTP 404» и «Invalid typed array length»:** кэш браузера. `python -m http.server` отдавал страницу, `data/fan/index.json` и пакеты только с `Last-Modified` (без `Cache-Control`) — браузер по эвристике держал старую опись (с L-5, другой размер S-3) и старые пакеты, а `fetch()` при обновлении страницы (F5) их не обновляет. Воспроизведено на Софии (`tools/p42/tk696_stale_run.sh`): профиль, закэшировавший старую опись → «L-5: HTTP 404» на лонге, «размер пакета не сходится» на шорте; после правки тот же профиль с обычным обновлением страницы (F5) грузит лонг (91 872) и шорт (302 733) «все»; чистый профиль — так же.

**Правка:** адреса данных веера — `data/fan/…?v=<время index.json на сборке страницы>` (`tk593_page.py` подставляет, `FAN_V`); опись — `fetch(…, {cache: 'no-cache'})`; сервер страницы — `tools/p42/ml_page_server.py` (юнит `ml-page-8090`, `Restart=always`, ставит и перезапускает `ml_page_update.sh`): страница и описи — `Cache-Control: no-cache`, пакеты с `?v=` — `max-age=31536000, immutable` (проверено `curl -I`); пакет не нашёлся (404) или его размер не сходится с описью — опись берётся заново один раз (`cache: 'reload'`), без ошибки. Владельцу — один раз обновить страницу (F5).

**Сортировка таблицы веера:** клик по заголовку любого столбца («Линия», девять столбцов, «Сходство» при «похожих») — порядок по столбцу, повторный клик — наоборот (первый: имя, просадка, % маржи, перехай — по возрастанию, остальные — по убыванию; стрелка ▲ / ▼ в заголовке, `aria-sort`); порядок — по всем линиям набора (при топ N — по топ N), не по выборке рисования; состояние в хеше `so=<ключ>:<d|a>`, переживает ползунки, смену уровня и ссылку; «порядок» (Шарп / сумма) его сбрасывает; пустые значения — в конце. На узком экране (≤ 640 px) заголовки остаются строкой над карточками. Проверка `tk684_fan_check.js`: каждый столбец, первый и второй клик, значения 30 строк == независимый счёт по пакетам; после ползунков, по ссылке, на другом уровне.
