## Слово владельца

> пропуск по тикам без событий делать не надо потому что гипотезы разные бывают.
>
> ищи другие варианты

(25.11.2026 ≈ 02:15 GMT+4, ответ на оценку TK-706: пропуск тихих блоков тиков — модель −30…−45 % CPU.)

## Суть

Ускорение движка `breakout tick` (TK-706) не выкидывает тики из прохода: каждый тик остаётся виден коду стратегии, потому что будущие гипотезы могут смотреть на любой тик. Рычаг «пропуск тихих блоков» снят; ищутся другие — общий проход по входу (ветвление вариантов, все тики), раскладка и ширина данных, сборка (LTO / PGO / target-cpu / mimalloc), минутки один раз на партию в памяти. Решение координатора: результат по-прежнему байт в байт против текущего бинаря.
