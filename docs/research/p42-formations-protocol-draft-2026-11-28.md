### 13.82.1 Формации: определения на минутных барах, только прошлое, пороги назначены до счёта — ЧЕРНОВИК 28.11.2026 v1

V — RV60(t−1) в bp. «Окно(a…b)» = закрытые минуты t−a … t−b. Окна: **P** = (30…1) — «пауза» (30 минут, как `NCONS` TK-712); **B240** = (270…31) — 240 минут перед паузой (как `NBASE`); **I** = (90…31) — «нога», 60 минут перед паузой; **W_s** = (120…1) — окно сетапа для заколов, 120 минут (= 2 · H, H = 60; назначено). Знак «слабый» — `weak_f = 1`.

**F1 — F-imp (трендовый рост монеты на объёме → остановка → продолжение; для шорта — падение).** Все шесть условий, все — по закрытым минутам до t:
- (a) **нога:** m_I = (c_{t−91} − c_{t−31}) / c_{t−91} · 10⁴ / V ≥ **2,0** (падение за 60 минут не меньше 2 V; «2 σ-часа» — назначено);
- (b) **трендовость:** ER_I = |c_{t−91} − c_{t−31}| / Σ_{i ∈ I} |c_i − c_{i−1}| ≥ **0,30** (коэффициент эффективности хода; у случайного блуждания на 60 шагах ≈ 0,10 — **модель**; назначено);
- (c) **заход объёма в ноге:** S_I = Q_I / (Q_24 / 24) ≥ **2,0**, где Q_I = Σ_{i ∈ I} q_i, Q_24 = Σ q_i за 1 440 минут (1530…91) перед ногой («оборот ноги в два раза выше среднего часа монеты за сутки»; назначено; конструкция φ4, окно сдвинуто на 30 минут назад);
- (d) **остановка (сжатие):** ρ_P = mean_P[(h−l)/c] / mean_{B240}[(h−l)/c] ≤ **0,75** (`CR_MAX` TK-712);
- (e) **уровень не взят:** min_{i ∈ P} c_i ≥ L (ни одного закрытия ниже уровня в паузе; проколы тенью допускаются);
- (f) **остановка у уровня:** d(c_{t−1}) ≤ **1,0 · V** (закрытие предыдущей минуты не дальше 1 V выше уровня).
Продолжение (пробой) — **сам сигнал** (вход в зону на минуте t): отдельным условием не проверяется (иначе заглядывание). Если окно I, P, B240 или Q_24 не полное (правило 1 §13.82) → н/о. `weak_imp = 1 − F1`.
Описательно (не решает): воронка (a); a∧b; a∧b∧c; +d; +e; +f; **флаг** — откат паузы к ноге r_P = (max_{i ∈ P} c_i − c_{t−31}) / (c_{t−91} − c_{t−31}) ∈ (0; 0,5] при F1 = 1 («формация флаг») — доля и $ отдельно, без решающей роли (по слову владельца «остановка для формирования пробоя»).

**F2 — F-casc (закол каскада; основное определение — код репозитория: за уровнем в сторону пробоя).**
- **Члены каскада** C(L, t): 1m-пивоты-минимумы (K = 5: low бара j строго ниже low пяти баров слева и не выше пяти справа; подтверждён закрытыми барами, j + 5 ≤ t−1; возраст ≤ 1 440 минут, `AGE` TK-712) с ценой P_j, (L − P_j) / L ∈ **[0,002; 0,006]** (`CASC_LO, CASC_HI`), **не взятые** к началу окна: нет закрытия ниже P_j на минутах j+5 … t−121 («уровень, через который цена уже прошла, в каскад не входит»).
- **Закол члена j** (в окне W_s): ∃ бар b ∈ W_s, b > j + 5: l_b ≤ P_j · (1 − **0,001**) (допуск 0,10 %, `TOL` TK-712) **и** c_b ≥ P_j (ушла за уровень и вернулась в той же минуте).
- n_C = |C|, n_stab = число членов с заколом (в окне W_s). **F2 = 1 ⇔ n_stab ≥ 1.** `weak_casc = F2`. Нет членов (n_C = 0) → F2 = 0 (формации нет, **не** н/о).
- Следствие: заколом члена цена прошла за L; «закол самого уровня L» (проколы тенью, `pierce_ep` TK-588) — **отдельная** величина, здесь не берётся (прежнее чтение TK-588, §13.82.3 п. 6).
- **F2′ (описательный вариант, не решает):** члены на подходной стороне: (P_j − L) / L ∈ [0,002; 0,006] **выше** L (зеркало брошюры, стр. 8: «ниже ещё один и самый свежий»), закол — вниз и возврат: ∃ b ∈ W_s, b > j + 5: l_b ≤ P_j · (1 − 0,001) ∧ c_b ≥ P_j. Печатаются доли и ход ≥ 1 V; решения не двигает.

**F3 — F-cons (проторговка у уровня; определение TK-712 / TK-714, зеркало для шорта).** F3 = 1 ⇔ (i) ρ_P ≤ 0,75; (ii) min_{i ∈ P} l_i ≥ L (в паузе уровень не прокалывается тенью — `ok_a`); (iii) max_{i ∈ P} c_i ≤ L · (1 + **0,008**) (коридор 0,8 %, `BAND` TK-712 — число гайда «больше 0,8 % — далеко»). `weak_cons = 1 − F3`. Н/о при неполных P или B240. Перекрытие с F1(d)(e): F3 строже по тени (ii); F1 допускает проколы тенью — это различие и печатается (§13.82.2 п. 1).

**F4 — F-sharp (резкий подход).** r_max = max_{i ∈ (4…1)} (h_i − l_i); r_P = mean_{i ∈ P} (h_i − l_i). **F4 = 1 ⇔ r_max > 3,0 · r_P** (`SHARP_N, SHARP_X = 4, 3,0` TK-712, `ok_d`). `weak_sharp = F4`. Н/о при неполном P.

**F5 — F-saw (пила / вертолёт).** Для баров P с h > l: тень-доля w_i = (h−l−|c−o|) / (h−l), тело-доля b_i = |c−o| / (h−l); alt = число пар соседних баров P с (c−o)_i · (c−o)_{i−1} < 0. **F5 = 1 ⇔ mean(w) ≥ 0,6** (`HELI`, вертолёт) **или** (mean(b) ≥ 0,6 **и** alt ≥ 15) (`SAW_BODY, SAW_ALT`, пила) — `ok_e`, `ok_f` TK-712 с обратным знаком. `weak_saw = F5`. Н/о при неполном P.
