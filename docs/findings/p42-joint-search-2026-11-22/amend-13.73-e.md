## 3. Чтение уровня

Как §13.73.3 разд. 3, с четырьмя осями: база', охраны (а)–(д), стоп выше базы' не считается; плато (г) — соседи на шаг по каждой из четырёх осей; победитель — правило §13.73.1; рядом — лучшая охранённая клетка с плато со всеми четырьмя сдвинутыми осями. Планка нижних уровней четвёрки — наибольший Шарп из: база'; `best1` её осей; лучшие охранённые (а)–(д) клетки её пар и её посчитанных троек. «Четвёрка добавляет» = лучшая клетка со всеми четырьмя сдвинутыми осями выше планки и Σ ≥ Σ базы' — описание («найдено на этих данных»), не доказательство. Отчёт — формат §13.73.3: одна строка на набор сделок; первыми R:R и убыток по цене стопа, худшая сделка, Σ $, $ на сделку, число сделок, Шарп, просадка, перехай; без медиан и бп; строки не складываются — торгуется одна линия. Ничего не замораживается. Пятёрки не считаются (приказа нет).

## 4. Счётчик испытаний и шум

m стороны на момент чтения = все клетки стороны в БД: после троек 16 314 (лонг) / 26 764 (шорт), + новые клетки пар оси `split` (768 / 784, §13.73.4) + новые клетки четвёрок (19 925 / 19 990) → ≈ 37 000 / 47 500 (больше — если раньше чтения досчитаны тройки с `split`, раздел 5). Шум = σ Шарпа клеток уровня × √(2 ln m): при σ ≈ 1,05 (как у клеток троек) ≈ 4,8 / 4,9 Шарпа, при σ ≈ 1,5 ≈ 6,9 / 7,0 (верхняя оценка, клетки зависимы). В отчёте печатаются обе оценки: по σ клеток четвёрок и по σ клеток карты пар (1,69 / 1,45).
