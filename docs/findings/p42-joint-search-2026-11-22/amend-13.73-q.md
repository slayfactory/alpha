## 2. Бинарь шага

`/data/p42-tk683/bin/alpha-tk683k-plain.c400af11` (k; md5 c400af112bda3396d807b2ba882aea8b, sha256 5d94addf876527ce4f44deabb8363ee3cc44acf1bd51fea37f1ba93dc9817fb1; TK-683, коммит `b19fa881b`): PASS критика; гейт `gate683k1.json` — 600 клеток c539 (3 324 файла, 264 клетки с фильтром), 0 различий, `bad` = []; он же G-base (`TK674_GBASE`). Смена h → k — на границе шага (шаг 3 закончен, L-353): md5 добавляется в `res/eqbins674.json` и записывается `note` в летописи; клетки шагов 2–3 не пересчитываются, клетки шага 4 считаются на k целиком. Настройки: `P42_WIDE=200`, `--cap-gb 16`, `--sig-cache`, потоки 4, один движок за раз, стороны по очереди (`TK674_SEQ=1`), MemoryMax 40G; лёгкие партии без фильтра (меньше 20 проходов сигналов) — до 800 вариантов на вызов (`TK674_VMAX_LIGHT=800`, совет TK-683: постоянная часть вызова ≈ 4,5 с; набор клеток не меняется, меняется только состав партий), партии с фильтром и тяжёлые — до 400 вариантов и 26 проходов, как на шаге 3.

**Канарейки (FIX 2).** Гейт на вызовах по 800 вариантов не проходил, поэтому `TK674_CANARY=10`: в первую лёгкую партию больше 400 вариантов каждой стороны (во всех трёх окнах) добавляются до 10 клеток без фильтра, уже лежащих в БД с прежних партий по 400 вариантов (шаги 2–3, те же проходы сигналов, по кругу по проходам); их файлы (`trades`, `daily`, `coinday`, `entryrej`) сверяются с готовыми байт в байт ДО отметки готовности партии; любое различие — стоп (`SystemExit`), остальные партии не считаются. ## 4. Время, место, счётчик

Время — модель на допущении (0,027 с на вариант-окно по шагу 3 на h, поправка на число проходов сигналов на вариант: лонг ×0,55, шорт ×1,9): счёт ≈ 0,25 ч (лонг) + ≈ 0,9 ч (шорт), затем `tables` / `ccheck` / `map` ≈ 0,5 ч; уточняется по журналу первых вызовов. Место ≈ 4 ГБ (каталог клеток после шагов 2–3 — 4,4 ГБ; на `/data` свободно 84 ГБ).

m стороны = клетки стороны в БД на момент чтения (клетки c539 + клетки h775 той же стороны, PS-975 разд. 6) + новые клетки троек: лонг 50 699 + 19 995 = 70 694, шорт 76 430 + 19 992 = 96 422. Шум ≈ σ·√(2 ln m) при σ шага 3: лонг ≈ 1,51 × 4,73 ≈ 7,1, шорт ≈ 1,35 × 4,79 ≈ 6,5 (верхняя оценка, клетки зависимы; пересчитывается по картам). Сравнение — прирост Шарпа к планке нижних уровней тройки (PS-956 разд. 3) против шума; одна линия торгуется, строки не складываются.
