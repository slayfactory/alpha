Поправка к §13.73.6 (PS-959) и §13.73.10 (PS-963): четвёрки с осью `split` и дельта троек со значениями 80 / 90 % — потолки клеток и правило отсечения. Записана ДО отбора и ДО счёта: карта `bs3` ещё не построена, P&L клеток троек с осью не читался.

## 1. Зачем

Постоянный приказ владельца (В-171, дословно): «как переберешь всен двойки и ди на тройки. как закончатся тройки иди на чептверки». В-173 № 34 (дословно): «добавляй 80 и 90 процентов». Бинарь оси (`alpha-tk677.93cb51a9`) считает ≈ 4,2 с на клетку и держит до 26 ГБ на 20 проходов сигналов — стороны идут по очереди (22.11: две стороны вместе — OOM в пределах 40 ГБ юнита; `TK674_SEQ=1`). Потолок клеток назначается заранее, чтобы объём не выбирался по результату.

## 2. Дельта троек: значения 80 / 90 % (к PS-963 разд. 5)

Отбор — после карты `bs3`, по пересобранной карте пар `map674bs` (14 значений оси, вердикт L-320): `TK674_REBASE=1 TK674_SPLIT=1 TK674_SPLITW=1 tk674_level.py select 3 <потолок>`; правило §13.73.3 без изменений (активная пара, «≥ 2 из 3», порядок по сумме приростов активных пар, комбинации берутся целиком). Считаются только клетки, которых нет в БД. **Потолок новых клеток: 2 000 на сторону** (≈ 2,3 ч движка на сторону). Тройки за потолком не считаются и перечисляются в таблице «за потолком» — их отсутствие в карте не читается как «не работает».

## 3. Четвёрки с осью `split` (к PS-959 разд. 4, §13.73.5 разд. 5)

Отбор — по карте `bs3` после её вердикта: `TK674_REBASE=1 TK674_SPLIT=1 TK674_SPLITW=1 tk674_level.py select 4 <потолок>`; правило §13.73.5 без изменений (активная тройка — лучшая охранённая (а)–(д) клетка с плато со всеми сдвинутыми осями выше планки нижних уровней и Σ не ниже Σ базы'; четвёрка берётся, если активны ≥ 2 её троек; порядок — по сумме приростов активных троек, затем имя; целиком). Считаются только клетки, которых нет в БД (четвёрки без оси посчитаны, L-304 / L-315). **Потолок новых клеток: 3 000 на сторону** (≈ 3,5 ч движка на сторону). За потолком — как в разд. 2.

## 4. Порядок до счёта

После каждого отбора (без движка, без P&L новых клеток) — отдельный раздел «до счёта» с таблицей «есть / считаем» (активных комбинаций нижнего уровня, комбинаций по правилу, взято, за потолком, клеток, есть в БД, считаем, проходов сигналов) и списком взятых комбинаций; затем критик; затем юнит. Потолки разд. 2 и 3 после отбора не меняются. Если отбор даёт 0 новых клеток — уровень закрыт записью в летописи без счёта.

## 5. Чтение, счётчик, шум

Как §13.73.6 разд. 2–3 и §13.73.10 разд. 4: одна строка на набор сделок; R:R и убыток по цене стопа «только A» / «A + B» первыми; число и средний $ стопов каждого вида; доля исполненной части B и средний исполненный размер; Σ $, $ на сделку, число сделок, Шарп, просадка ($, % маржи, % от Σ), перехай; якорь стороны рядом. По В-173 строки со стопом 5 % в таблицы владельца не идут (в карте клетки с e2t > 0 и стопом 5 % остаются обычными клетками §13.73.4, с пометкой). Аудит TK-682: метки `_q` — «подобран на этих данных», ось SHARP не читается, повторы наборов сделок считаются один раз, у клеток `bm3` стопы после 1-го тейка — отдельной колонкой (L-319). m стороны = все клетки стороны в БД на момент чтения; шум = σ × √(2 ln m), печатаются оценки по σ клеток уровня и σ клеток карты пар. Описательно, «найдено на этих данных»; ничего не замораживается; торгуется одна линия.
