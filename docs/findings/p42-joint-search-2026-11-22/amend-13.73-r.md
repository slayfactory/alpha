## 2. Правило чтения (решение критика, дословно по смыслу)

- (а) **Строки без строки TK-671** клетку недействительной не делают. На каждую прочитанную строку — число её зачётных сделок на таких строках (из сделок БД) и **Σ $ и Шарп с ними и без них**: `tk674_emptycols.py without` (ряд и Шарп как в `tk674_run._row_job`).
- (б) **`bd_*`:** клетки недействительны по счётчику (как у TK-690: архив удалён TK-675, 100 % NaN в wa); остаются в m, не читаются.
- (в) **`cc_*`:** клетки не читаются, пока TK-690 не найдёт причину расхождения `cc_*` у ZEC. Если NaN «не определено по определению» — клетки валидны как записаны, и в каждой прочитанной строке печатается «фильтр не определён на X % сделок» по окнам; строка с X > 0 хотя бы в одном окне — не кандидат на заморозку без отдельной проверки критика.
- (г) **Реализация:** `TK674_WITHHOLD=bd,cc tk674_level.py map <n>` — клетки этих классов не входят в победителей, плато, планку нижних уровней; **m и σ шума считаются по всем клеткам** (m не уменьшается, σ — по Шарпам всех посчитанных клеток); в выводе карты — число клеток каждого класса (`withheld`). Без переменной карта прежняя (лонг и шаги 2–3 не пересчитываются). Тесты: `test_tk674_emptycols.py`.
- (д) **Финальные кандидаты (не более двух на сторону):** для каждого печатается доля сделок, допущенных по NaN / по отсутствующей строке таблицы, по каждому столбцу его фильтра и по всем столбцам вместе — по окнам (по сделкам кандидата, окно за окном). Кандидат, у которого эта доля **> 50 % сделок хотя бы в одном окне**, не замораживается (указание координатора 23.11); п. (в) действует сверху: любая строка с `cc_*` и X > 0 хотя бы в одном окне — отдельная проверка критика.
