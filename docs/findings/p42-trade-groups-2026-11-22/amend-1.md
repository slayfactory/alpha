## 13.76а Поправка 1 к PS-970 (TK-685, до стадии join) — ключ присоединения признаков

**Основание (измерено 22.11 до счёта признаков по исходам; сверялись только ключи сделок и строк матрицы, исходов и столбцов `y_*` не читали).** В п. 5 ключ присоединения — `(win, sym, sig_ms, level)`. Столбец `level` в `*-trades.csv` движка и `meta_level` матрицы TK-671 — разные нумерации: ключ с `level` совпадает у 52 из 428 сделок L_A, 33 из 319 S_A, 161 из 3 875 L_W, 174 из 2 912 S_W. Ключ `(win, sym, sig_ms)` находит в матрице хотя бы одну строку у 427 из 428 (L_A), 317 из 319 (S_A), 1 770 из 3 875 (L_W, 45,7 %), 2 040 из 2 912 (S_W, 70,1 %) сделок; у остальных строки нет — сигналов этих сделок в матрице нет (другой прогон движка; сдвига по времени нет: у L_W ближайший сигнал той же монеты в пределах 10 мс есть лишь у 1 771).

**Что меняется.**
1. Ключ — `(win, sym, sig_ms)`; `level` в ключ не входит.
2. Дубль ключа (на один сигнал несколько уровней; у всех 20 дублей L_A и 25 дублей S_A векторы признаков строк различаются). Файл сделок движка цены уровня не несёт (`level` — другая нумерация), поэтому строку выбирает цена: подразумеваемая цена сигнала строки `px_impl = meta_level_px_e8 · (1 − meta_dist_e8 / 1e8)` у лонга, `· (1 + meta_dist_e8 / 1e8)` у шорта (проверено на строках без дубля: медиана расхождения с `entry_px_e8` — 1,5 бп L_A / 2,0 бп S_A, обратный знак — 55 / 27 бп); берётся строка с наименьшим `|px_impl − entry_px_e8|`; при равенстве или пропуске — с наименьшим `meta_dist_e8`; при равенстве — первая в порядке матрицы. Правило не точное (у 13 из 20 дублей L_A и 13 из 25 S_A вторая по близости строка дальше лучшей минимум на 2 бп): неверная строка добавляет шум в признаки уровня, а не смещение к исходу. В таблице набора печатается: сделок без дубля, выбрано по цене, по `meta_dist_e8`, по порядку, не присоединено. Для справки к каждому контрасту по половине 1 считаются AUC всех признаков и на сделках **без дубля** (только эталон, кандидатов и подтверждения не меняет). По правилу п. 5 без поправки (дубль с разными векторами → не присоединена) S_A присоединялся бы у 292 из 319 = 91,5 % < 95 %. Правило записано до того, как признаки сопоставлены с исходами; столбцы `y_*` по-прежнему не читаются (у всех строк дубля метки совпадают, различить строки они не могут).

**Не меняется:** ворота G-join ≥ 95 % сделок набора, пригодность, шумы, пороги, α_set = 0,05 / 8, правило вердикта.

**Следствие по уже записанному правилу (не поправка):** L_W (45,7 %) и S_W (70,1 %) не проходят G-join → признаки этих наборов не считаются (п. 5, «охват печатается»); путь и группы исхода описываются по всем четырём наборам; признаки проверяются на L_A и S_A, число испытаний п. 10 — по прошедшим ворота наборам (поправка α_set остаётся на 8 проверок).
