3. **№ 9: ключи `tn` / `tno`** (только `breakout tick`; определение дословно — докстрока `ExitCfg::tn_pct`, `src/breakout/params.rs`): `tn` — доля позиции, %, которую закрывает ПЕРВЫЙ тейк, поставленный у следующего уровня (0 — выкл., по умолчанию; допустимо 1…100); `tno` — отступ этого тейка от уровня внутрь, NATR (0 по умолчанию; `tno ≠ 0` при `tn = 0` — ошибка разбора). Следующий уровень — ближайший по цене уровень той же монеты СТРОГО за пробиваемым по ходу сделки из того же набора уровней, что дал сигнал, из известных и живых на минуте сигнала (`born ≤ t < end`; заглядывания вперёд нет). Цена тейка = следующий уровень − `tno` · NATR (шорт зеркально). Тейк заменяет ступень 1 лестницы; на остатке (100 − `tn`) % лестница работает как обычно (ступени с ценой выше тейка), всё, что не ушло в тейки, — обычный выход (стоп, безубыток, трейл). **Откат на обычную лестницу** (исход байт в байт как без ключа): следующего уровня нет; тейк не по ту сторону цены входа; расстояние тейка больше внешней ступени лестницы.

## 3. Чтение, активная ось, вердикт (записано до счёта)

Как PS-1000 п. 5 и §13.73.7 п. 5, без изменений: по каждой из шести осей все значения рядом с якорем (база стороны): число сделок, Σ $, $ на сделку, Шарп (годовой по суточному ряду), просадка $ и % маржи, перехай (самый длинный, средний, p90, хвост), R:R и убыток на полный стоп (`tk680_owner.py`); охраны (а)–(д) и плато (среднее Шарпа соседей по порядку значений оси: `tn` 25 → 50 → 100; `tno` 0 → 0,1 → 0,25; `lk` 2 → 3 → 4; `ld` 1 → 3 → 5; `lsl` 0 → 0,5 → 1 → 2; `tf` при `lx = 4`: 30 → 60); без медиан и без бп в ответах владельцу. **Вердикт описательный — «найдено на этих данных»**; активная ось = победитель оси проходит все охраны, Шарп выше якоря и Σ $ не ниже якоря (правило `tk680_singles.py map`). Счётчик испытаний `m` — как у PS-1000: все прежние клетки плюс **28 клеток набора** (14 на сторону); на 24.11 05:10 GMT+0 в БД лонг 202 334 (c539 163 673 + h775 38 661), шорт 965 950 (c539 917 052 + h775 48 898) — **с набором 202 348 и 965 964** (растёт с четвёрками TK-674; в вердикте — значение на момент `map`); шум отбора — по суткам, как у PS-1000. Клетки `lx = 4` торгуют другое множество сигналов: в таблице рядом с каждой клеткой печатается **число сделок базы и клетки** (в разы больше базы у `lx = 4` — это не прирост качества, а другое множество); положительный Шарп клетки без превышения Шарпа якоря активной осью не считается. **Активная ось `lx = 4`** — отдельная линия-кандидат (другое множество сигналов, не считалось вместе с четвёрками TK-674): входит в отбор-пререг только своей линией, со своим `m`, и не складывается с клетками четвёрок. **Допущение «линия внутри минуты неподвижна» не измерено (п. 11 PS-960): до вердикта измеряется без P&L** — для сделок `lx = 4` окна wa (каждая клетка и объединение) |наклон| · 30 с в бп цены (p50 / p90 / макс) и доля > 1 бп; **если p90 > 1 бп, `lx = 4` активной не бывает, пока линия не версионируется по точному времени.** Подтверждение — только одной проверкой на июне 2026 после заморозки (В-170), по правилам PS-960 п. 5 (одна линия торгуется, перехай и просадка — условия отбора). Результат читается один раз, после того как записаны вердикт и числа по правилу выше; значений и клеток после чтения P&L не добавляют.
