# П-42: все признаки и параметры (опись на 22.11.2026)

Что это: полный список параметров движка пробоя уровня (`src/breakout/params.rs`) и столбцов таблицы признаков, по темам. Для каждого — что значит, значение в базе и участие в общем переборе (TK-674).

Источники: `params.rs` ветки `bb/tk-677-split-entry-v1-thr_hgrv7c5qqt` (включает ключи TK-674, TK-676, TK-677); оси — `tools/p42/tk674_axes.py` ветки `bb/tk-674-joint-search-holdout-v1-thr_6uj9ukb5m4`; база — `docs/research/freeze/tk626-frozen.json` (`cells`: L_base, S_base, S_mk1); столбцы таблицы — `ml_features.json` и код TK-654.

Как читать:

- **База** — замороженные линии проверки вперёд (Л — лонг, Ш — шорт). Если ключ в линии не задан, действует значение по умолчанию — оно и показано.
- **Перебор** — значения в двойках, тройках и четвёрках TK-674; «нет» — параметр не двигался.
- Расстояния — в процентах цены. NATR — средний размах минутной свечи монеты за 30 минут, в процентах цены. Ставка 500 $ — константа движка, комиссии — тариф владельца, ключами не задаются.
- Смысл взят из комментариев в коде; формулы в `tick.rs` построчно не сверялись (см. «Не подтверждено»).

**Важно.** Ключ `mk` — это вход лимитной заявкой, а не история пробоев монеты. Признак владельца «число минимально успешных пробоев монеты» (TK-625, столбцы `n_ok`, `ok10_d14`) есть только в таблице признаков: в базе, в замороженных линиях и в общем переборе его нет.
