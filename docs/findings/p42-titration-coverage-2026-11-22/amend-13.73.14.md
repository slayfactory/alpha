## 4. Чтение, активная ось, вердикт

Как §13.73.7 п. 5 и условия §13.73.10 / §13.73.11, без изменений: по каждой оси все значения рядом с якорем (база стороны) — число сделок, Σ $, $ на сделку, Sharpe (годовой по суточному ряду), просадка $ и % маржи, перехай (самый длинный, средний, p90, хвост), R:R и убыток на полный стоп (`tk680_owner.py`); охраны (а)–(д) и плато (среднее Sharpe соседей по порядку значений оси — для `nf` пороги 0,2 → 0,4 → 0,6, для `ev` множители 0,5 → 1 → 2, для `el` / `eh` с родителем посередине, для `sm` — от `sm0`); без медиан и без бп. Вердикт — описательный, **«найдено на этих данных»**, линия не меняется, ничего не замораживается. Оговорки, печатаемые рядом: 914 клеток — не 914 независимых испытаний (семейства `acc*`, `kyle*` / `amih*`, `mk*` сильно коррелированы; `≤ q` и `≥ q'` пересекаются; восемь источников волатильности — одна и та же величина с разным окном); шум отбора — σ Sharpe клеток × √(2 ln m), `m` — все клетки стороны в БД на момент чтения. Ось читается только вместе с контрольной клеткой `nf3`: если её сделки не равны базе (п. 2.1), оси `nf*` описательно не читаются до новой поправки.
