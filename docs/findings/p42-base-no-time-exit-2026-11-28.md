## Шаг 3. Страница :8090

- **«Эквити»**: вариант «база, без выхода по времени» (`san`) рядом с «база, стоп 4 %» (`sa`): числа те же (172 сделки, Σ +133,93 $, Шарп 3,63, просадка 25,81 $, перехай 41 сут. — окно 01.07–13.11), линии совпадают.
- **«Сделки»** (хеш `#trades/<период>/<группа>[/<№ сделки>]`, периоды: фев–13.11 · январь · 14–24.11 · все): сводка групп (клик — фильтр), таблица сделок (время GMT+4, монета, вход, выход, как вышли, $, группа, 12 чисел сетапа; сортировка по столбцам), клик по сделке — минутные свечи ±2 ч от входа и выхода, линия уровня, отметки входа и выхода, числа сетапа. Всё в долларах.
- **«Выход (ср.)»** — средняя цена всех частей выхода (тейки и остаток) по итоговому P&L на 500 $; отметка стоит на минуте последнего выхода, поэтому у сделок с тейками она может лежать вне свечи этой минуты. Вход на 54 из 532 сделок лежит вне минутной свечи на ровно 0,01 % (цена заявки против свечи по сделкам).
- **Проверка:** клик-тест Софии `tk741_check.js` — 247 сверок (1280) и 249 (390), 0 провалов, ошибок консоли 0: число сделок и сводка групп по каждому периоду == БД, фильтр по каждой группе, сортировка 8 столбцов в обе стороны, график 7 сделок (свечи, уровень, вход, выход на своих местах по цене и времени), ссылка воспроизводит вид, узкий экран без перелива; прежний `tk684_check.js` — 4 898 сверок на обеих ширинах, 0 провалов (вариант `san` входит).
