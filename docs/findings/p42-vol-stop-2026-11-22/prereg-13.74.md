## 1. Вопрос

Даёт ли стоп, расстояние которого зависит от волатильности на входе (NATR или реализованная, окна 5 / 15 / 30 / 60 минут), линию лучше, чем фиксированный стоп с тем же потолком (≤ 4 % цены), на сторонах L и S базовой линии П-42? Жёсткий стоп 5 % в кандидатах не участвует (потолок расстояния ≤ 4 %); строка базы с 5 % печатается только как справка.

Опровергает: ни одна охранённая клетка стороны не лучше лучшего фиксированного стопа ≤ 4 % (п. 7). При «да» — клетка становится кандидатом на проверку вперёд (В-170; торговля — отдельное решение владельца). При «нет» — стоп остаётся фиксированным, запись «не работает» с перечнем проверенного.

## 3. Определения

- `V` — волатильность в процентах цены на закрытой минутке перед сигналом (`sig_min − 1`), заморожена на входе; стоп считается один раз на сделку.
- Источник `vs`: 1–4 — NATR с периодом 5 / 15 / 30 / 60 минутных баров (как `natr_of` движка); 5–8 — реализованная волатильность RV_h = √Σ r² за h = 5 / 15 / 30 / 60 минут, **r — простая минутная доходность c_t / c_{t−1} − 1 (не логарифм)**, целочисленно (`rv_of`).
- Форма `vf`: 1 — `d = a·V`; 2 — `d = b + a·V`; 3 — `d = a·V^p`; 4 — `d = a·ln(1 + V / v0)`. Режимный множитель (`vz`, `vr` = ρ): `V` заменяется на `V·(V_z / V)^ρ`.
- Итог зажат в `[vm, s]` (верх главнее низа), `s` — потолок расстояния, % цены. Нет значения источника → действует `s`. Цена стопа `e − d` (шорт `e + d`), округление 0,001 %.
- Параметризация «стоп при среднем V̄»: T — расстояние стопа при средней волатильности источника на сигналах базы (среднее L и S из `desc676.md`): N5 0,71, N15 0,64, N30 0,59, N60 0,50, R5 1,06, R15 1,72, R30 2,32, R60 2,90 (% цены). Коэффициент `a` выводится из T и округляется до 2 значащих цифр: линейная a = T / V̄; аффинная a = (T − b) / V̄; степенная a = T / V̄^p; логарифм v0 = c·V̄, a = T / ln(1 + 1/c); режимная a = T / (V̄_vs^(1−ρ) · V̄_vz^ρ).

Соседи для (г): этап 1 — соседние T той же семьи (форма, источник, доп. параметр, потолок) и та же клетка на соседнем окне того же вида (NATR 5↔15↔30↔60, RV так же; у режимных — только T); этап 2 — соседние значения своей оси (значение базы = родитель).

Выбор: победитель стороны — охранённая (а)–(д) клетка этапов 1–2 с наибольшим годовым Шарпом по суточному ряду; при разнице ≤ 0,1 — с меньшим самым длинным перехаем, затем с меньшей просадкой. Опора стороны F — фиксированный стоп `s` = 3 или 4 (клетка БД) с большим Шарпом.

Вердикт по стороне:
- **«работает»** (кандидат вперёд, с пометкой «найдено на этих данных»): победитель есть; Шарп победителя > Шарпа F и Σ ≥ Σ F; нижняя граница 95 % интервала парной суточной разницы Σ (победитель − F; блочный бутстреп по суткам, блок 5, 20 000 повторов, seed 676) > 0; парная разница Σ (победитель − F) > 0 минимум в 3 из 4 складок по 34 суток (складки §13.73); прибавка Шарпа над F ≥ ожидаемого максимума шума выбора σ·√(2 ln m_р), σ — выборочная ошибка разницы Шарпа (победитель − F) по блочному бутстрепу по суткам (блок 5, 20 000 повторов, seed 676), m_р — число клеток раздела стороны; общий m стороны печатается рядом.
